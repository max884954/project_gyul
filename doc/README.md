# Project Documents

이 폴더는 GGeul 게임 기획 문서를 관리합니다.

## Files

- `GGeul_게임기획서.docx`: 최초 첨부된 원본 기획서입니다.
- `GGeul_게임기획서_다듬은_사본.docx`: 정리 또는 편집된 사본입니다.
- `GGeul_구현요청서_마일스톤별.docx`: 구현 요청을 마일스톤별로 정리한 문서입니다.
- `GGeul_인게임_UIUX_플로우_및_카드Hover_상세설명_기획안.docx`: 인게임 UI/UX 플로우와 카드 hover 상세 설명 개선안을 정리한 검토용 Word 문서입니다.

## Rules

- 최신 작업본은 파일명에 날짜나 상태를 명확히 붙입니다.
- 원본 기획서는 직접 덮어쓰지 않고, 필요한 경우 사본을 만들어 수정합니다.
- Godot 구현 작업에서 참고한 주요 변경점은 필요하면 이 폴더에 별도 메모로 남깁니다.
- 신규 기획/역기획 문서는 필요 시 Markdown 초안과 Word 검토본을 함께 남겨, 빠른 수정과 공유 검토를 모두 지원합니다.
